# Editorial redesign — implementation plan

Spec: `docs/superpowers/specs/2026-11-23-portfolio-redesign-design.md`, section "Revision 2". Visual reference (approved mockup, plain HTML): `.superpowers/brainstorm/55905-1795428834/content/editorial.html`. Match its look; port it to React + Tailwind.

Branch `redesign/portfolio-v2`. Stack: Vite 7, React 19, TS, Tailwind 3.4 (`darkMode: ['class']`), Vitest + Testing Library + jsdom. Commands: `npm test`, `npm run lint`, `npm run build`. Commit after each task (message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`).

Ground rules
- All copy comes from `src/data/portfolio.ts` or `src/data/ask.ts`. Do not invent facts, numbers or titles.
- Every interactive element has a visible focus ring (`focus-visible:outline-2 outline-offset-2 outline-ink` or equivalent).
- Respect reduced motion via `usePrefersReducedMotion` from `src/lib/motion.ts`.
- Storage only via `src/lib/storage.ts`; theme via `src/lib/theme.ts` (keep both and `theme.test.ts`).
- Layout must work from 320px to 1440px with no horizontal scroll.
- Avoid template tells: no all-caps eyebrow labels, no `→` on links, no cards/shadows/gradients, no monospace.
